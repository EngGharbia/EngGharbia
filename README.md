I'm a full-stack engineer with **10+ years** of experience. I lead the IT Management Department at Libya's Economic Information & Documentation Center (EIDC), Ministry of Economy & Trade, where I run the ministry's e-government platforms and manage the engineering team. Most of my work is in .NET and Flutter: I design the database, build the API, and ship the web and mobile apps on top of it.

I enjoy the hard parts of fintech and government software: payments that can't lose money, identity checks, and Arabic-first interfaces that feel right. Nearly all of my code is written for government agencies and private clients, so it lives in private repositories. **Project details are on [bengharbia.ly](https://bengharbia.ly).**

## Selected work

- **Foreign Companies Registration System**: registers foreign company branches for Libya's Ministry of Economy & Trade under Decree 207/2012 rules, with parallel approvals by the consulate, companies registry, minister and bank; 7-role RBAC and an 8-step bilingual wizard. Live in production. *.NET&nbsp;10 · Next.js&nbsp;16*
- **EIDC Compulsory Insurance Mobile**: compulsory vehicle-insurance platform with a Decree 126/2022 premium calculator, QR policy verification and OCR plate lookup for officers. *Flutter · .NET&nbsp;10*
- **Mauthuq**: production wallet and gift-card ecosystem with multi-currency deposits and withdrawals, Tron/USDT payments, KYC document verification and NFC card support; its APIs enforce idempotency and velocity controls. *ASP.NET&nbsp;Core&nbsp;10 · Flutter*
- **PaymentGateways System**: payment orchestration for SWAPay, exposing one merchant API over 8+ regional and international processors (including Stripe, PayPal, Almadar, Moamalat and Coinbase), with real-time webhooks and per-gateway fees. *.NET&nbsp;10 · Blazor&nbsp;Server*
- **Madmun**: Arabic-first gift-card platform for Libya with payments through Sadad, OnePay, Almadar, Stripe and PayPal; idempotent money path with automatic refunds and reconciliation workers. *.NET&nbsp;10 · React&nbsp;19 · Flutter*
- **HuwiyaGate**: multi-tenant KYC for Libyan organizations with passport OCR/MRZ, face matching and liveness detection; results go out through an outbox and HMAC-signed webhooks, with tenants isolated by SQL Server row-level security. *.NET&nbsp;10 · Next.js&nbsp;16 · Flutter&nbsp;SDK*

I've also delivered systems for the Ministry of Civil Service (Tansibat nominations platform, Wadhifati citizen app), Libya's Insurance Supervision Authority (insurance statistics system) and Response Center 1448 (clinical management for COVID-19 isolation centers nationwide).

More projects, including the Wirsal WhatsApp/SMS gateway and the Mishwar ride-hailing platform, are on **[bengharbia.ly](https://bengharbia.ly)**.

## Tech stack

- **Backend:** C# / .NET 8–10, ASP.NET Core Web API, EF Core, Dapper, SignalR, Hangfire, Clean Architecture / CQRS
- **Web and mobile:** Flutter (Riverpod, BLoC), Blazor (Server & WASM), .NET MAUI, React / Next.js, TypeScript, Tailwind CSS, Arabic RTL / i18n
- **Data:** SQL Server (stored procedures, row-level security), Redis, SQLite / Drift
- **Payments and integrations:** Stripe, PayPal, Coinbase and regional gateways, Tron/USDT, KYC / biometric verification, WhatsApp / SMS / OTP, Firebase Cloud Messaging
- **Delivery and ops:** GitHub Actions CI/CD to Windows IIS, Serilog, OpenTelemetry, Grafana, Prometheus, Docker, Kubernetes
- **Practices:** idempotency and resilience (Polly), RBAC and security hardening, automated testing (xUnit, Vitest), audit logging
